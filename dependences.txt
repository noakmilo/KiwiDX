KiwiDX v0.2.0 - Runtime Requirements
=====================================

Operating system
----------------
- Windows 10 or Windows 11.
- A 64-bit Windows installation is recommended.

Required runtime
----------------
- Setup and release ZIP include .NET 8 (self-contained x64).
- Source framework-dependent builds require Microsoft .NET 8 Desktop Runtime (x64).
- Download: https://dotnet.microsoft.com/download/dotnet/8.0
- Select ".NET Desktop Runtime" for Windows x64.
- The .NET SDK is not required to run KiwiDX.
- Microsoft Edge WebView2 Runtime (required for the receiver map and embedded WebSDR support).
- WebView2 download: https://developer.microsoft.com/microsoft-edge/webview2/
- Windows Media Foundation MP3 encoder (included with supported Windows 10 and Windows 11 installations).
- The bundled ffmpeg.exe must remain beside KiwiDX for 480p MP4 waterfall recording.

Hardware and connectivity
-------------------------
- A Windows-compatible audio output device.
- An Internet or local-network connection to a supported receiver.
- Firewall access to the HTTP/HTTPS and WebSocket port used by the selected KiwiSDR server.

Files that must be distributed together
---------------------------------------
- KiwiDX_v0.2.0.exe
- KiwiDX_v0.2.0.dll
- KiwiDX_v0.2.0.deps.json
- KiwiDX_v0.2.0.runtimeconfig.json
- Microsoft.Web.WebView2.Core.dll
- Microsoft.Web.WebView2.WinForms.dll
- The complete runtimes folder generated in Release.
- NAudio.dll
- NAudio.Asio.dll
- NAudio.Core.dll
- NAudio.Midi.dll
- NAudio.Wasapi.dll
- NAudio.WinForms.dll
- NAudio.WinMM.dll

Optional file
-------------
- KiwiDX_v0.2.0.pdb is only needed for debugging and crash diagnostics.

Installation
------------
1. Run KiwiDX_v0.2.0_Setup_x64.exe, or extract the entire release ZIP.
2. The installed and published application is KiwiDX.exe; source builds use KiwiDX_v0.2.0.exe.
3. Install future Setup versions over the existing installation.
4. User preferences are stored in %LOCALAPPDATA%\KiwiDX and retained on upgrade/uninstall.
5. On first launch, select the old portable folder when prompted to migrate its settings.

No separate NAudio installation is required. Its libraries are included with KiwiDX.
